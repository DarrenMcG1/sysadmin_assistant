## One thing worth knowing before you touch the project queries

The suite mocks every database session, so a `WHERE` clause is invisible
to it. Moving the freshness filter into SQL means
`tests/test_project_snapshots_query.py` asserts the predicate compiles
into the statement rather than that Postgres evaluates it — the two
board tests that proved a deleted project was dropped could not survive
the move and were replaced with wider but shallower coverage. A live
integration test is filed in [tasks.md](../roadmap/tasks.md).
